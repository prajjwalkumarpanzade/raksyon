What R-Secure doesn't do
          
It doesn't sit between your AI tools and their model providers. Claude Code and Cursor still talk to their own services, as they do today.

          
To keep a critical file out of a model's context, the hooks stop the read before it happens. For everything else, R-Secure records the access so your team knows exactly what each AI tool saw.

        

      

    

  


  

    

      

        
Six promises
A security tool that doesn't become a security risk.

        
R-Secure sees the same sensitive files your AI tools do, so it's built to keep almost nothing.

      

      

        
01
Secrets are never stored
When a key or password turns up, only the rule name and an 8-character fingerprint are kept. The secret never reaches a log, a database or a report.

        
02
Contents scanned in memory
File contents are checked on the developer's machine and thrown away immediately.

        
03
Secrets in commands redacted
A key typed into a command is replaced with a redacted marker before anything is saved.

        
04
Self-hosted
All activity data lives on your server. The license check carries counts, never content.

        
05
No slowdown for developers
The hooks write one line and exit. If your R-Secure server is down, AI tools keep working normally.

        
06
Hard to switch off quietly
Tampering with R-Secure's files or hook settings is itself flagged. On Linux, the kernel watcher runs as a protected system component the AI tools can't edit.

      

    

  


  

    

      Your controls
      
You decide what's kept, and for how long.

      

        
Retention
Older events are deleted from your server automatically. Saved daily reports aren't affected.
90 days by default

        
Prompt logging
Record what developers asked, or turn it off for the whole organization.
On or off

        
Users and roles
Admin accounts with roles decide who can see activity in the dashboard.
Per person

        
Machine tokens
Every developer machine has its own access token. Revoke one and that machine stops sending events.
Per machine

        
Where it runs
Agents run on Linux (Ubuntu), macOS and Windows. The kernel watcher runs on Linux only.
Your machines
