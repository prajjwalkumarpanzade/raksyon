Kernel watcher

Hooks only see what the AI tool reports. The bpftrace watcher sees what it doesn't: scripts and subprocesses the agent starts, and files touched outside the hook path. These events are marked indirect and lead the daily report.

FAQ

Questions teams ask before they deploy.

Can't find your answer? Talk to us.

What is R-Secure?

R-Secure is self-hosted security for AI coding tools. It records every file, secret and command that tools like Claude Code and Cursor touch on your developers' machines, and blocks the critical ones before they happen.

Does any of our code or activity data leave our network?

No. Every event goes from the developer's machine to your R-Secure server, inside your network. Nothing is sent to RAKSYON. The only outbound call is the license check, which sends the number of agents, the number of events and the server version, never file names, commands, prompts or code.

Does R-Secure store our secrets?

No. Files are scanned in memory on the developer's machine and thrown away. When a key or password turns up, only the rule name and an 8-character fingerprint are kept.

What does R-Secure detect and block?

It ships with 61 built-in rules covering secrets, cloud credentials, private keys, destructive commands, privilege escalation and more. For critical rules, the hooks stop the read or the command before it happens. Everything else is recorded and flagged.

Do we need MDM or a VPN?

No. Each developer runs one small single-file agent that sets up the AI tool hooks itself and reports to a server you host. Traffic isn't rerouted, and it doesn't matter whose account the AI tool is signed in to, including personal subscriptions.

What happens to developers' AI tools if the R-Secure server goes down?

They keep working normally.

Which operating systems are supported?

The agent runs on Linux (Ubuntu), macOS and Windows. The kernel watcher, which catches indirect reads by scripts, is Linux only.

How do we deploy it?

Install the R-Secure server on any machine in your network with your license key, create a token for each developer machine, and have each developer run the agent. Events appear in the dashboard within seconds.

How is R-Secure priced?

Per developer, with one seat covering one developer. Plans are Trial, Starter and Enterprise, all self-hosted. Contact us for numbers.
